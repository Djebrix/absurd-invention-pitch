One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: the TV remote vanishing between the couch cushions. The invention is a sofa that sneezes the remote back out, so the rescue mechanism itself is the joke.

> "The Cushion-Sneeze Sofa is a couch that, the instant your remote slips between the cushions, sneezes it right back into your lap with a polite little ah-choo."

Run `python3 main.py` with `ENTRY_OUTPUT_DIR` set to write the sentence to `entry.txt`.
